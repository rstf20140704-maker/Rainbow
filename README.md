# 彩虹臭薯條 A43 · 點餐系統操作說明

一頁看懂：怎麼開店點餐、怎麼改價格、怎麼看營收、出問題怎麼辦。

---

## 一、系統長什麼樣子

這套系統有兩個部分：

| 部分 | 是什麼 | 放在哪裡 |
|---|---|---|
| 前台點餐頁面 | 店員點餐用的網頁 | GitHub Pages 網址 |
| 後台資料庫 | 記錄每一筆訂單、算營收 | Google Sheets「StreetPOS 訂單系統」 |

兩者已經接好，點餐頁面送出訂單後，資料會**自動**寫進 Google Sheet，不用手動輸入。

---

## 二、每天開店：怎麼點餐

1. 手機瀏覽器打開點餐頁面網址（建議先「加入主畫面」，開店時像開 App 一樣點一下）。
2. 點選顧客要的口味，選**原份**或**大份**，用 ＋／－調整數量。
3. 下方訂單區確認品項與總金額無誤。
4. 選擇付款方式（現金／Line Pay／全支付／街口／其他）。
5. 按「送出訂單」，畫面會顯示訂單編號與金額，代表成功。

**如果網路不穩、送出失敗**：畫面會顯示「送出失敗」，剛剛選的商品**不會消失**，等訊號恢復後再按一次「送出訂單」補送即可，不用重選。

## 三、怎麼改價格 / 成本 / 上下架商品

打開 Google Sheet →「Products」分頁：

| 欄位 | 說明 |
|---|---|
| 商品名稱 | 口味名稱，**不要改**（要跟點餐頁面的名稱完全一致，改了會對不到） |
| 份量 | 原份／大份，同上不要改 |
| 售價 | 顧客付的金額，**可以改**，改完立即生效，不用重新部署 |
| 成本 | 這一份的進貨成本，用來算毛利，**可以改** |
| 是否啟用 | 目前僅供參考記錄，尚未接到前台的上下架功能 |

> 改「售價」只會改 Google Sheet 這裡的紀錄參考用；**點餐頁面實際顯示的價格是寫在網頁程式碼裡**，如果要改前台顯示的售價，要請工程師（或回來問我）改 `index.html`。

## 四、怎麼看營收 / 生意好壞

打開 Google Sheet：

- **Daily Analysis**：每一列是一天，看今天營收、訂單數、平均客單價、熱銷口味、付款方式占比、毛利。
- **Monthly Analysis**：每一列是一個月，看整月營收、熱銷Top5、生意最好的時段、星期幾生意最好、整月毛利率。

這兩張表**每次有新訂單送出就會自動重新計算**，不用手動整理。

## 五、常見問題

**Q：訂單編號長怎樣？**
`ORD-年月日-時分秒-三碼亂數`，例如 `ORD-20260810-142557-379`，同一筆訂單裡不同商品會共用同一組編號。

**Q：忘記點餐頁面網址了？**
GitHub 帳號登入 → 進到這個 repository → Settings → Pages，網址會列在那裡。

**Q：Orders 資料是不是可以隨便刪？**
測試階段的假資料可以刪。**正式營業後的真實訂單建議不要刪**，那是唯一的營收紀錄。

**Q：改了 Products 的成本，舊訂單的毛利會跟著變嗎？**
不會。成本是**下單當下**寫進 Orders 的快照值，之後改 Products 成本只影響**之後的新訂單**，這是刻意設計，讓歷史毛利維持下單當時的真實狀況。

## 六、給未來維護者（技術備查）

- 後端程式碼：Google Sheet →「擴充功能」→「Apps Script」裡的 `Code.gs`。
- **改完程式碼一定要「部署 → 管理部署作業 → 版本選新版本 → 部署」**，單純儲存不會讓上線網址生效，這是最容易忘記的一步。
- 想確認線上是不是最新版本：瀏覽器直接打開部署網址，看回傳 JSON 裡的 `version` 欄位，跟 `Code.gs` 第一行附近的 `CODE_VERSION` 對照。
- 前台原始碼：`index.html`（含 `images/` 資料夾內的商品照片），放在 GitHub repository 裡，用 GitHub Pages 發布。
- `index.html` 裡的 `GAS_URL` 常數要指向 Apps Script 部署網址，兩邊斷線的話前台會自動退回「本機模擬模式」（訂單不會真的寫入 Sheets）。
